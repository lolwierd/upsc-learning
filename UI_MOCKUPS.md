## Color Scheme

- **Direct CA (Current Affairs)**: Blue (`bg-blue-100 text-blue-800`)
- **Derived Static (Trending)**: Purple (`bg-purple-100 text-purple-800`)
- **Pure Static**: Gray (`bg-gray-100 text-gray-800`)
- **Grounding/Verified**: Yellow-green (`bg-yellow-100 text-yellow-800`)
- **Success/Correct**: Green (`bg-green-100 text-green-800`)
- **Error/Incorrect**: Red (`bg-red-100 text-red-800`)

## Icons

- 📰 Current Affairs
- 📊 Trending Topics
- 📚 Static/Textbook
- ✓ Verified Sources
- 🔗 External Link
- ↗ Open in new tab
- 💡 Insights

## Responsive Behavior

### Mobile (< 640px)
- Stack badges vertically
- Collapse stats into accordion
- Show simplified source list (domain only)

### Tablet (640px - 1024px)
- 2-column layout for filters
- Horizontal badge layout
- Full source display

### Desktop (> 1024px)
- Side-by-side stats and questions
- Hover tooltips for additional info
- Expanded grounding details
